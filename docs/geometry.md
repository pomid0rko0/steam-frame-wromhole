# Геометрия и метод

## Пространство

Червоточина из видео optozorax — трёхмерная гиперповерхность в плоском четырёхмерном пространстве R⁴, заданная 4D SDF:

```
union_round(плоскости w = ±h, extrude_w(сфера ρ₀, h), R)
```

Два плоских мира — гиперплоскости w = +h и w = −h — соединены сферой радиуса ρ₀, вытянутой вдоль четвёртой оси (это горло), а места соединения скруглены радиусом R. В видео ρ₀ = 0,3, h = 0,5, R = 0,1; здесь 1 единица = 10 м: горло радиусом 3 м и длиной 10 м, скругление 1 м.

Поверхность SO(3)-симметрична, поэтому её метрика выписывается точно:

```
ds² = dl² + r(l)² dΩ²
цилиндр    |l| ≤ Lc:       r = ρ₀                     w = l
скругление Lc ≤ |l| ≤ L:   r = ρ₀ + R(1 − cos θ)      w = ±(h − R + R sin θ),   θ = θ₀ + (|l| − Lc)/R
плоско     |l| ≥ L:        r = |l| − L + Rout         w = ±h
Lc = max(h − R, 0),   θ₀ = asin(max(1 − h/R, 0)),   L = Lc + R(π/2 − θ₀),   Rout = ρ₀ + R
```

l — длина дуги профиля от середины горла (l > 0 в мире A, l < 0 в мире B), r(l) — радиус сферы на этом расстоянии, w — четвёртая координата. Мир трёхмерный: w нужна только чтобы задать его форму, ходить и светить можно лишь по самой поверхности.

| | |
|---|---|
| точка | (l, n): l вдоль профиля, n — единичный вектор направления от центра |
| касательный вектор | (U_l, u): компонента вдоль l и поперечная часть, u ⊥ n |
| вложение в R⁴ | E = (r(l) n, w(l)) |
| карта (плоские координаты мира) | в A x = r(l) n, в B то же с отражённой осью x |
| горло, скругление, оболочка | \|l\| ≤ Lc, Lc ≤ \|l\| ≤ L, вся кривая зона \|l\| < L |
| пол | экваториальная поверхность n_z = 0 |

Пол вполне геодезический, поэтому продолжается сквозь горло: по нему можно пройти из мира A в мир B.

**Связь с ОТО.** Если добавить время без гравитационного замедления часов, получится статическое пространство-время `−dt² + ds²` — червоточина Морриса–Торна с нулевой функцией красного смещения. Свет в нём в проекции на пространство идёт ровно по геодезическим `ds²`, так что картинка точна и для этой червоточины ОТО. В видео те же геодезические приближаются шагами «шаг вперёд + проекция на поверхность»; здесь они считаются точно.

**Длина горла.** При постоянном скруглении R:
- **h < R** — скругления сходятся изломом, у r(l) острый минимум, круговой орбиты света нет: червоточина похожа на плоский шар, повторов миров нет;
- **h = R** — появляется цилиндрический участок («момент T» в видео): дальше растёт только число повторов, и в центре начинаешь видеть себя;
- **h > R** — на цилиндре поперечные лучи замкнуты: фотонная сфера, много повторов.

## Почему луч считается быстро

1. **Луч лежит в плоскости через центр** — следствие сохранения момента импульса b. Угол в этой плоскости — одномерный интеграл `ψ = ∫ b dl / (r √(r² − b²))`.
2. **На цилиндре** интеграл берётся в замкнутом виде.
3. **На скруглении — без циклов.** В переменной `u = sin²(θ/2)` угол равен `∫ F(u) dv`. F гладкая, а вся трудность — корень в точке поворота и логарифм при `b → r_min`, из-за которого лучи у фотонной сферы много раз огибают горло, — собрана в весе `dv = du / (2√(u(u − σ)))`, `σ = (b − ρ₀)/2R`. F заменяется многочленом по четырём точкам (квадраты узлов Гаусса–Лежандра), а моменты многочлена с точным весом берутся в замкнутом виде (product integration). Интеграл до любой точки пути — та же формула, поэтому точка падения на пол — два шага Ньютона. Где рекурсия моментов во float32 неустойчива, гладкий множитель веса переходит в многочлен.
4. **Коэффициенты многочлена зависят только от b**, поэтому шейдер берёт их из таблицы (`WormholeSpace.fillet_table`, 4 строки по 256 узлов, по строке на участок b с одним видом моментов), а видеокарта интерполирует. Множитель `1/√mx`, уходящий в ноль как корень у края оболочки, из таблицы вынесен и возвращается в пикселе: так интерполяция не теряет точность у края. Таблица строится при старте и строится заново при смене формы горла.
5. **Вне кривой зоны лучи прямые**, и предметы там пересекаются с лучом аналитически.
6. **Пол внутри оболочки — без лишних арктангенсов.** На луче `n_z` — синусоида по углу в плоскости луча, начинающаяся с плюса, с нулями через π. Луч доходит до пола внутри оболочки, только если поворачивает на π и больше или выходит из оболочки с `n_z < 0`; угол точки пола и шаги Ньютона считаются лишь для таких лучей.
7. **Длина пути для дымки — оценкой** `r²/b · ψ` с r в средней по весу точке: ошибка до 1,5% длины (до 7% на длинных скруглениях), дымка меняется меньше чем на 0,3%, а шейдеру нужно на один многочлен меньше регистров.

Как это ложится на шейдер и экран — в [rendering.md](rendering.md).

## Точность

`ref/wh.py` повторяет метод шейдера во float64, а `ref/test_fast.py` сверяет его с прямым интегрированием геодезической (RK4) на пяти профилях — видео, h = R, излом h < R, тонкая оболочка, длинное скругление — по 240 лучей на профиль:
- класс луча (пол, выход из оболочки, сквозь горло) совпадает везде;
- на профиле видео точка выхода из оболочки отличается не больше чем на 7·10⁻⁵ ρ₀, направление — на 2·10⁻⁵ рад (0,001°), точка на полу — на 6·10⁻⁵ ρ₀;
- хуже всего на изломе (h < R): 7,5·10⁻⁴ ρ₀ и 4,5·10⁻⁴ рад.

Сам шейдер во float32 против эталона — в [checks.md](checks.md).
